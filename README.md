## About

An entry for the make.fun bounty
[u-rama-melon-make-the-ai-judge-laugh-302d0825](https://make.fun/bounty/u-rama-melon-make-the-ai-judge-laugh-302d0825):
a program that writes a single joke about office life — one line, under
200 characters — to `/output/entry.txt`.

make.fun bounty: `u-rama-melon-make-the-ai-judge-laugh-302d0825` — $2 prize, free entry.

## Entry

> The office printer only jams on urgent documents, which is how I know it reads the subject line before I do.

108 characters. One line, built on a true office observation (the printer
always jams when it matters most) with a surprising turn at the end: the
printer isn't broken, it's reading your email before you do — the machine
has become the office gossip. No pun, no stock setup, reads cleanly aloud
in one breath.

## Run

```
node main.ts
```

Writes the line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`). Deterministic, no dependencies, no network, no cost.
